## About The Project

[![Product Name Screen Shot][product-screenshot]](https://example.com)

A sleek, modern expense tracker app built with Expo and Supabase, designed to make managing your money effortless. The standout feature? You can import and parse your bank statements directly into the app, so your expenses are automatically categorized and tracked.

### Features

- Automatic Bank Statement Parsing – Upload CSV or PDF statements and let the app categorize transactions instantly.

- Real-time Sync – All data stored securely in Supabase, available across devices.

- Intuitive Dashboard – Visualize your spending with charts, summaries, and insights.

- Quick Actions – Add, edit, or categorize expenses in a few taps.

- Offline First – Works even without internet, syncs when online.

### Security & Privacy

All sensitive data is securely stored in Supabase. Bank statements are processed locally or on a secure server before storage – your financial data is never shared.


   ```bash

   ```

### Installation

1. Get a free API Key at [https://example.com](https://example.com)
2. Clone the repo
   ```sh
   git clone https://github.com/yzhedwin/sh-moni-app.git
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Enter your API in `config.js`
   ```js
   const API_KEY = 'ENTER YOUR API';
   ```
5. Change git remote url to avoid accidental pushes to base project
   ```sh
   git remote set-url origin yzhedwin/sh-moni-app
   git remote -v # confirm the changes
   ```
